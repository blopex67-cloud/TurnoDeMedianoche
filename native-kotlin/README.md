# Turno de Medianoche — Android Kotlin nativo

Implementación nativa en Kotlin y OpenGL ES 2.0, sin Unity/Godot ni HTML. Escenario procedural de terror, animatrónico original, movimiento táctil, linterna, fusibles, salida y juego horizontal. El viejo prototipo Unity sigue separado en la carpeta superior; esta variante se encuentra aquí.

El APK debug se genera con GitHub Actions (workflow manual o push a `native-kotlin/**`). El build demuestra que compila, no sustituye la validación en un teléfono físico.
